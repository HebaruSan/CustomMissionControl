Custom Mission Control
Developed by CrapShot79
Custom Mission Control is an immersive, real-time web dashboard for Kerbal Space Program. It allows you to monitor your vessel's telemetry on a second monitor or tablet via a clean, CRT-style interface.

## Features
Real-Time Telemetry: Monitor altitude, velocity, and orbital data (AP/PE/TTA).

Interactive Navball: CRT-style attitude indicator for pitch and roll.

Smart Consumables: Track Liquid Fuel, Oxidizer, Solid Fuel, and Monopropellant.

Stage Markers: Visual dividers on the fuel bar show you exactly how much fuel is in each stage.

Time-to-Depletion: Advanced logic calculates exactly how much burn time you have left based on your current throttle.

## Installation
Download the latest CustomMissionControl.zip from the Releases section.

Extract the CustomMissionControl folder into your KSP GameData directory.

Launch KSP. The dashboard will automatically open in your default browser once you are in flight.

## Privacy & Safety
Your data is your own. * 100% Local: This mod runs a tiny "Localhost" server on your own machine. No data is ever sent to the internet or any external servers.

Browser Sandbox: The dashboard runs in your standard web browser, ensuring it cannot access your private files.

Firewall Note: If Windows Defender asks for permission, it is simply allowing the KSP game to "talk" to the dashboard on your own computer.
